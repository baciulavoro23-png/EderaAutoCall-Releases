# EderaAutoCall

Distribuzione ufficiale e aggiornamenti automatici di EderaAutoCall.

## Installazione corretta

1. Apri la sezione **Releases**.
2. Scarica esclusivamente `Installa-EderaAutoCall-VERSIONE.exe`.
3. Esegui l’installer e usa il collegamento **EderaAutoCall** creato sul Desktop.

> Non avviare direttamente `EderaAutoCall.exe` dallo ZIP: lo ZIP è il pacchetto tecnico usato dal sistema di aggiornamento e, se aperto manualmente, non esegue il launcher.

## Aggiornamenti

Aprendo EderaAutoCall dal collegamento installato, il programma controlla automaticamente la presenza di nuove versioni. Quando ne trova una mostra le novità e permette di scegliere **Riavvia e aggiorna** oppure **Ricordamelo più tardi**.

Chi ha usato in precedenza l’EXE estratto dallo ZIP deve eseguire una sola volta l’installer 1.4.0; i dati personali non vengono cancellati.
